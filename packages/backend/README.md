# @minamatch/backend

Backend de MinaMatch V2 — Express + PostgreSQL (Drizzle ORM).

## Propósito

- API REST versionada (`/api/v2/...`)
- Autenticación JWT con refresh tokens (sin guest-token)
- Logger estructurado (Pino)
- Tests de integración

## Estado actual

Estructura inicial vacía. El backend V1 actual está en `server/`.
La migración a este package será gradual.
